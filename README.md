# city-traffic-forecast-system

Қалалық жол кептелістерін талдау, модельдеу және болжау ақпараттық жүйесі.

Жүйе қала жолдарындағы трафик деректерін жинап, талдайды және кептеліс деңгейін болжайды. Ол көлік жүйесін жоспарлайтын мамандарға және жол қозғалысын басқару орталығына арналған.

## Мақсаты

Тарихи және нақты уақыттағы трафик деректері негізінде кептелістерді талдап, болжау арқылы көлік шешімдерін қабылдауға көмектесу.

## Пайдаланушылар

- Трафик аналитигі
- Диспетчер (жол қозғалысын басқару орталығы)
- Қала жоспарлаушысы
- Әкімші

## Талаптар

1. Аналитик жол учаскелері бойынша трафик деректерін қарап, кептеліс картасын көреді.
2. Жүйе датчиктерден, GPS-тен және сыртқы дереккөздерден трафик деректерін жинап, дерекқорға сақтайды.
3. Аналитик аймақ пен уақыт аралығын таңдап, кептеліс болжамын сұратады.
4. Жүйе тарихи деректер бойынша болжау моделін іске қосып, нәтижені көрсетеді.
5. Қала жоспарлаушысы жол желісіндегі өзгерісті (жолды жабу, бағдаршам уақыты) модельдеп, нәтижелерін салыстырады.
6. Диспетчер кептеліс деңгейі шектен асқанда ескерту алады.
7. Аналитик талдау және болжам есептерін PDF/Excel форматында жүктеп алады.
8. Әкімші пайдаланушыларды және олардың қол жеткізу рөлдерін басқарады.
